# Pulluru Vanitha Portfolio

Modern responsive portfolio built with React + Vite + CSS.

## Run locally

1. Install Node.js.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

The supplied profile PDF is available as `public/Profile.pdf` and is linked from the Resume button.
